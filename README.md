# درع — منصة عربية لأمان الويب

نموذج MVP تجريبي لواجهة عربية RTL لفحص أمان المواقع وتحليل الروابط المشبوهة.

## تشغيل ��لنسخة التجريبية

لا تحتاج إلى تثبيت حزم أو إعداد خادم خلفي. افتح `index.html` مباشرة في متصفح حديث، أو استخدم خادم ملفات ثابتة محليًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ما الذي يعمل الآن؟

- واجهة عربية متجاوبة مع اختيار بين فحص الموقع وتحليل الرابط.
- شاشة نتائج توضيحية لفحص الموقع مع مرشحات لمستوى الخطورة وإرشادات معالجة.
- تحليل محلي شكلي للرابط يرصد بعض المؤشرات مثل عنوان IP، وعلامة `@`، وبعض خصائص اسم النطاق.
- سجل آخر التحليلات محفوظ محليًا في المتصفح (`localStorage`) مع إمكانية مسحه.
- لا توجد مكتبات خارجية ولا تُرسل البيانات إلى خادم.

## حدود الأمان والدقة — مهم

هذه **محاكاة واجهة وليست أداة فحص أمنية فعلية**. نتائج فحص الموقع ثابتة للتوضيح، وتحليل الرابط لا يتصل بخدمات السمعة أو DNS ولا يفتح الصفحة ولا يلتقط صورة لها. لا تعتمد ��لى النتائج لاتخاذ قرار أمني، ولا تدخل بيانات حساسة بناءً عليها. لا تستخدم النموذج لمهاجمة أو فحص أنظمة الآخرين.

## خطة البناء بعد اعتماد النموذج

1. إضافة اختبارات واجهة وإمكانية الوصول، ثم اعتماد التصميم والتدفق.
2. بناء API مستقل بـ FastAPI وPostgreSQL وRedis/Celery للفحوصات السلبية المصرح بها.
3. إضافة طبقات دفاع SSRF، وحدود المعدل، وعزل أدوات الفحص وسجلات التدقيق قبل دمج أي ماسح.
4. التحقق من ملكية النطاق وجلسات تفويض محدودة زمنيًا قبل أي فحص نشط غير هدّام.
5. إضافة الحسابات، مقارنة النتائج، تتبع الإصلاحات، التقارير، والتنبيهات.

لا يُفعّل الفحص النشط أو أي استكشاف للمسارات أو المنافذ في هذا الـMVP.
